# Christian Schuler, Researcher Homepage

Live version of my researcher homepage at [christianschuler8989.github.io](https://christianschuler8989.github.io/).

The pages in this repository are generated. They are built from my research records by a static site generator in a separate development project, reviewed locally, and then copied here as one release. Changes made by hand in this repository are replaced by the next release.

Every page works without JavaScript. JavaScript only adds enhancements such as filters and the language selection.
