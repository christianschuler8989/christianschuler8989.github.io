An interactive map of dialectal diversity across Kurdish varieties

Summary

An interactive map visualising dialectal diversity across Kurdish varieties, based on the Database of Kurdish Dialects (Matras, 2016).

Overview

The Kurdish Linguistic Variations Map is an interactive web application that visualises dialectal diversity across Kurdish varieties. Starting from the idea by Murat Baran, the prototype maps lexical and phonological variation using data from the Database of Kurdish Dialects (Matras, 2016). Users can explore how specific words and features vary across geographic regions and dialect groups.

Data Source

The primary data source is the Database of Kurdish Dialects compiled by Yaron Matras (2016), which contains systematic lexical elicitation data from a wide range of Kurdish varieties. This structured dataset makes it possible to generate comparative visualisations across dialect boundaries in a reproducible way.

What It Shows

  • Geographic distribution of lexical variants for selected concepts across Kurdish varieties.
  • Boundaries and transition zones between major dialect groups (Kurmanji, Sorani, Zazaki, Gorani).
  • Point-by-point comparisons of how individual words surface in different dialects.
