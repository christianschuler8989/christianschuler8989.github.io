A Feature Analyses Navigation tool for cross-linguistic comparison

since 2022
Status
active
People

Summary

A Feature Analyses Navigation (FUAN) tool for exploring and comparing linguistic features across language varieties and families.

Overview

LOVE - Language Ontologies & Varieties Explorer - is an interactive tool for exploring and comparing linguistic features across language varieties and language families. One of its components, the Feature Analyses Navigation (FUAN), was developed together with Yusser Al Ghussin and allows researchers to navigate typological feature databases in a visual, query-driven way.

Motivation

Typological databases like WALS (World Atlas of Language Structures) contain rich cross-linguistic data, but their standard interfaces can make it difficult to ask comparative or exploratory questions, particularly across multiple features simultaneously. LOVE aims to lower this barrier with a browser-based interface that brings together ontologies, variety classifications, and feature annotations in one place.

Features

  • Navigate linguistic features across language varieties using a visual interface.
  • Filter and compare languages by typological properties.
  • Integrates with the Kurdish Linguistic Variations Map for dialect-level data.
